# Retain

Retain is a personal expense and monthly budget manager. The project will use a React and TypeScript frontend with a Node.js/Express API backed by PostgreSQL.

The application will support expense tracking, monthly budgets, spending summaries, authentication, and an admin area for category management and platform insights.

## Project structure

- `frontend/` - React, TypeScript, and Vite frontend
- `backend/` - Node.js, Express, and TypeScript API
